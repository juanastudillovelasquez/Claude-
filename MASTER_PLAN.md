## Quiénes
Juan y Yussra. Dos fundadores, 12–15 h/semana cada uno (~27 h/semana combinadas, ~117 h/mes). Ambos con empleo actual.

## Qué construimos
Una empresa de **IA + Marketing + Automatización**, mercado inicial Chile.

## Para qué
- **Meta económica:** CLP 6.000.000/mes de utilidad neta combinada, sostenible.
- **Meta real:** dinero + tiempo + libertad. La empresa debe comprar nuestra libertad, no crear otro empleo.
- **Métrica estratégica:** utilidad + libertad generada por hora de fundador (definición en `METRICS.md`).

## Regla principal
`PROBLEMA → SOLUCIÓN → OFERTA → VENTA → RESULTADO → SISTEMA → AUTOMATIZACIÓN → DELEGACIÓN → ESCALA`

No se construye tecnología que no responda a un problema por el que alguien ya demostró que pagará.

## Principios operativos
1. Avanzar por Gates (`GATES.md`). Un Gate no aprobado no se maquilla.
2. Aprender solo lo que el Gate actual exige: `APRENDER → CONSTRUIR → PROBAR → CORREGIR → DOCUMENTAR → APLICAR`.
3. Toda herramienta se justifica por problema → función → costo → beneficio → necesidad actual (`TOOLS.md`).
4. Ningún fundador es punto único de dependencia: todo proceso repetido se documenta en `SOP/`.
5. Toda afirmación se etiqueta: **DATO / INFERENCIA / HIPÓTESIS / RECOMENDACIÓN**.
6. Prioridad semanal: 1–3 acciones, no listas largas.
