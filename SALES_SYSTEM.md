`investigar → detectar problema → clasificar → priorizar → registrar → contactar → seguir → reunión → propuesta → cierre`

| Etapa | Quién lo hará al inicio | Automatizable después |
|---|---|---|
| Investigar y detectar problema | Fundadores + IA | Sí (scraping + IA) |
| Clasificar / priorizar | IA con criterio escrito | Sí |
| Registrar | Planilla/CRM | Sí |
| Contactar | Fundadores (personalizado) | Parcial |
| Seguimiento | Recordatorios | Sí |
| Diagnóstico / venta | Fundadores | No (núcleo humano) |

Contactos → respuestas → reuniones → propuestas → cierres.
