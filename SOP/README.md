# SOP — Procedimientos estandarizados

Un SOP se escribe cuando un proceso se repitió **2 veces**. Antes es especulación; después es deuda.

## Formato (un archivo por proceso: `SOP/NNN-nombre.md`)
1. **Objetivo** — qué resultado produce.
2. **Disparador** — cuándo se ejecuta.
3. **Responsable** — titular y respaldo (nunca una sola persona).
4. **Pasos** — numerados, verificables.
5. **Herramientas**
6. **Tiempo estimado**
7. **Automatizable / delegable** — sí/no y por qué.
